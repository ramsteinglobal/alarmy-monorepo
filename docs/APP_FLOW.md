# Wakely — Flow & Features in Easy Words

> Living doc. Updated: scheduler wired + guest-first live. Keep this side-by-side while building.

## Big picture (1 line)

Wakely-style mission alarm: set time → phone rings → finish a small task to stop it → build a streak.

## Where you start (guest-first, no login needed)

1. Open app → **Splash** (Wakely logo while session loads + alarms reschedule).
2. Always land on **Alarm Dashboard** — alarms, ringing, and basic missions work fully as a guest, saved on the phone.
3. **Sleep / Morning / Report** show a friendly sign-in wall for guests (account = history, sync, personalization). **Settings** shows guest state with Sign In CTA.
4. Login/Signup push on top from any wall; after sign-in you return to where you came from.

## Free vs account vs subscription (plan)

- **Free, no account:** alarm CRUD, on-time ringing, basic missions. Local only.
- **Free account:** unlocks Sleep/Morning/Report, cloud backup + multi-device sync, sleep persona + personalization.
- **Subscription (later):** premium packs — personalized alarm tasks, exclusive music/tones, chained missions, extra-loud, wake-up check, full stats.

## Theme (light / dark / system)

- Palettes in `src/theme.ts` (`lightColors` + `darkColors`, identical keys), provided by `ThemeProvider` (`src/store/ThemeContext.tsx`), persisted at `@wakely_theme_mode`, default **system**.
- Every screen/component reads `useThemeColors()` — no static `COLORS` in UI (only the yellow brand splash + Google-blue icon stay fixed).
- Switch anytime in **Settings → Appearance**: Light / Dark / System. Status bar + tab bar follow automatically.

## Alarm tab (the only real flow)

```
Dashboard (countdown hero + mission chips) → (+) Create (label, live rings-in, batch days)
  → Sound (default from Settings) → Missions (up to 3 chained + tune + preview dry-run)
  → Summary (snooze length/count, auto-dismiss failsafe) → Save (saves + schedules exact OS triggers)
  → back to Dashboard
Ring (notification, Doze-proof, over lock screen) → Ringing (WAKE UP)
  → SNOOZE (per-alarm length/count, re-rings once) or START MISSION
  → Missions in order (Step X of N) → Success (mood check-in, stops sound)
  → history saved (chain ids, mood, snoozes) → Report shows streak % + per-mission stats
```

Missions (all real): Math (difficulty + 1-5 problems), Typing (1-3 reps), Memory (3-6 length),
Shake (real accelerometer + tap fallback), Squat + Tap Challenge (counter), Photo/Barcode (camera capture proof).
Guests use alarms fully; Sleep/Morning/Report need an account; logged-in users sync alarms/history/sleep to Firestore.

## Sound engine (real tones)

- 5 bundled WAV tones (`android/res/raw` + iOS bundle): Classic, Morning Rise, Energy Boost,
  Nature, Extra Loud (+ silence track for vibrate-only). Generated by `temp/opencode/gen-tones.js`.
- One Notifee channel per tone, so each alarm rings its own sound; per-alarm vibration honored.
- SelectSound has real ▶ preview through the actual alarm channel (~6s).
- Untouched ringing escalates to Extra Loud after 40s (backup watchdog, cancelled on engagement).
- Untouched auto-dismiss failsafe per alarm; wake-up check minutes after dismiss with 60s grace,
  then full re-ring (even from a killed app).

- **Dashboard** (`src/screens/alarm/AlarmDashboard.tsx`): list, on/off switch, edit, delete, pull-refresh. `NEXT ALARM` today = first ON alarm, not smartest/nearest (fix planned).
- **Create** (`CreateAlarmScreen.tsx`): hour/minute stepper, AM/PM, day chips Mon–Sun. Default = Mon–Fri. If you unpick all days it says `Once` but there is no date picker yet.
- **Sound** (`SelectSoundScreen.tsx`): 5 names (Classic, Morning, Energy, Nature, Vibrate-only). Stores the name only. No preview, no audio file yet.
- **Mission** (`SelectMissionScreen.tsx`): 7 cards (Math, Photo, Barcode, Memory, Typing, Shake, Squat).
- **Summary** (`AlarmSummaryScreen.tsx`): review + Save. Today only writes to `AsyncStorage @wakely_alarms`. Does NOT schedule OS alarm yet (scheduler code just landed, not wired — see below).
- **Ringing** (`AlarmRingingScreen.tsx`): big clock (current time), alarm card, `START MISSION`. Back button blocked. Dev-only `Dismiss for now` button.
- **Mission** (`MissionExecutionScreen.tsx`): routes to game + progress bar (only Shake updates bar today).
- **Success** (`AlarmSuccessScreen.tsx`): writes `@wakely_alarm_history {durationSeconds}` once, `DONE` → Dashboard, `VIEW REPORT` → Report tab.
